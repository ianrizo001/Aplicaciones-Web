Sobre GameWhiskers

Conoce un poco más sobre nuestro proyecto web.

¿Qué es GameWhiskers?

GameWhiskers es un sitio web creado para compartir información sencilla sobre videojuegos y algunos aspectos relacionados con la industria.

Objetivo

El objetivo del sitio es presentar información sobre diferentes videojuegos de una manera sencilla, organizada y fácil de consultar.

🐱 Nuestra identidad

El gato es el elemento característico de GameWhiskers. Se utiliza como una pequeña marca visual que aparece en las diferentes páginas del sitio.
